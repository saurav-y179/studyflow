Mode 1

Local LLM  · runs on your machine ·

No internet. Nothing leaves your device. Ever.

Imagine hiring a tiny genius to live inside your laptop. The AI model runs entirely on your computer — StudyFlow whispers to localhost:8000, a private door only your machine can open. Fast if you have a GPU. A little slower on CPU-only. Either way — zero cost, zero cloud.

The catch: you do need to download an inference engine and a model. Two steps, not twenty.

  • 1Download LM Studio (lmstudio.ai) or Ollama (ollama.com) — both free, both straightforward.
  • 2Pick a model: llama-3.2-1B (tiny, fast), phi-3-mini (great for older machines), or mistral-7b (smarter, needs 8 GB+ RAM).
  • 3Hit Start Server in the app. Confirm it's on port 8000. Different port? Update it in StudyFlow → Chat Settings → Custom Address.
  • 4Running on a different machine? Swap localhost:8000 for that device's local IP — a Raspberry Pi in the corner works perfectly.

AI Setup Guide

Three modes to power Pikachu. Change any time in Chat Settings → gear icon.

Mode 1 — Local LLM Free & Private

AI runs on your own computer. No internet needed. Nothing leaves your device.

  • Best for: privacy, offline use, machines with a GPU
  • Cost: free
  • Speed: fast with a GPU; slower on CPU-only

Setup

  1. Download LM Studio (lmstudio.ai) or Ollama (ollama.com)
    • LM Studio has a GUI; Ollama is lighter and command-line
  2. Download a model
    • llama-3.2-1B — small, fast
    • phi-3-mini — great for older machines
    • mistral-7b — smarter, needs 8 GB+ RAM
  3. Start the local server on port 8000
    • Different port? Update in StudyFlow → Chat Settings → Custom Address
  4. Running on another machine? Replace localhost:8000 with that device's local IP

Mode 2 — Cloud API Fast & Easy

AI runs on an external server. Get an API key and paste it in.

  • Best for: older laptops, minimal setup, fastest responses
  • Cost: free to very cheap — most have a free tier
  • Trade-off: messages travel to an external server

Where to get a key

  • Groq — console.groq.com — free, no credit card, extremely fast
  • Google Gemini — aistudio.google.com — free key, very capable
  • OpenRouter — openrouter.ai — one key, many models to choose from
  • Mistral AI — console.mistral.ai — free tier, European servers
  • Together AI — api.together.xyz — $5 free credit
  • OpenAI — platform.openai.com — small credit needed
  • Cohere — cohere.com — free trial tier
  • Anthropic — console.anthropic.com — Claude models

Exact Endpoint URLs

  • Groq: https://api.groq.com/openai/v1/chat/completions
  • Google Gemini: https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateContent
  • OpenAI: https://api.openai.com/v1/chat/completions
  • Anthropic Claude: https://api.anthropic.com/v1/messages
  • Together AI: https://api.together.xyz/v1/chat/completions
  • Mistral AI: https://api.mistral.ai/v1/chat/completions
  • Cohere: https://api.cohere.ai/v1/chat
  • OpenRouter: https://openrouter.ai/api/v1/chat/completions

Setup

  1. Sign up at any provider → API Keys page → generate a key
  2. StudyFlow → Chat Settings → Cloud API → paste key
  3. Set Endpoint URL
    • Groq: https://api.groq.com/openai/v1/chat/completions
    • Other providers: use the exact URL listed above

Mode 3 — Basic Offline No Setup

No AI. Pikachu uses 30+ pre-written cheerful responses.

  • Best for: first-time setup, or just wanting the UI alive
  • Won't answer real questions or analyse tasks
  • Setup: none — just select this mode

Auto-Fallback

StudyFlow never crashes due to a connection failure.

  • Local server off → falls back to Basic Offline automatically
  • Cloud API fails → same fallback
  • A small indicator tells you what happened

Quick recommendation

  • Start with Groq (Cloud API) — free, instant, no card needed
  • Switch to Local LLM later if you want full privacy or offline use
