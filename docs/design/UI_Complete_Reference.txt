================================================================================
1.  PROJECT OVERVIEW
================================================================================

StudyFlow is a habit-tracking / productivity dashboard application built with:

  - React 19 (via Vite)
  - Tailwind CSS v4
  - Framer Motion (animation library)
  - date-fns (date formatting)
  - Three.js / @react-three/fiber (3D starfield background)
  - Lucide React (icon library)
  - GSAP + ScrollTrigger (legacy App.jsx hero animations)
  - Express.js backend (file-based persistence, optional)

The app displays a personal study dashboard where users can:
  ✓ Register a profile (name, email, daily goal)
  ✓ Add/manage daily tasks (with auto-duration estimation)
  ✓ Plan tasks for tomorrow (with auto-tagging and time slots)
  ✓ Track streaks and momentum
  ✓ View an activity heatmap (year-long GitHub-style grid)
  ✓ Use a Pomodoro-style focus timer (4 presets)
  ✓ Chat with an AI assistant (Pikachu) — supports local/cloud/basic modes
  ✓ Connect external accounts (GitHub, HuggingFace, Reddit, etc.)
  ✓ Export all data as JSON
  ✓ Switch between multiple user profiles
  ✓ Switch app versions (v3 "Dashboard" / T2 "Editorial")

3.  DATA LAYER
================================================================================

3.1 useStudyFlow Hook (src/hooks/useStudyFlow.jsx)

  The central data hook consumed by every component.

  State:
    user      — currently active profile object { id, name, email, dailyGoal }
    entries   — array of day entries [{ date, todayTasks[], timestamp }]
    streak    — { current: number, longest: number }
    momentum  — { momentum: number (0-100), color: string }
    isLoading — boolean

  Actions:
    refreshEntries()     — re-reads entries from storage, recalculates streak/momentum
    registerUser(data)   — saves user to storage, updates state
    switchActiveProfile(id) — switches to another profile, reloads all data
    clearActiveProfile() — creates new blank profile, resets state to null

  Initialization (on mount):
    1. syncFromServer() — pulls data from Express API into localStorage
    2. promotePlannedTasks() — runs day-rollover logic (promotes yesterday's tasks)
    3. getUser() — reads active profile
    4. Auto-creates default user ('User', '', goal: '4') if none exists
    5. getEntries() — reads all entries for active profile
    6. calculateStreak() + calculateMomentum() — derives streak/momentum

3.2 Storage Layer (src/utils/storage.js) — 605 lines

  Persistence:
    - localStorage for fast local access
    - Optional Express API server (file-based) for cross-device sync
    - Server sync is background (fire-and-forget) unless explicit

  Key namespacing:
    studyflow_profiles       — array of all user profiles
    studyflow_active_profile — ID of current active profile
    studyflow_entries        — array of day entries (per-profile: studyflow_entries_{profileId})
    studyflow_promoted       — promotion tracking (per-profile)
    studyflow_connections    — external platform connections (per-profile)

  Key Functions:
    getUser() / saveUser()           — profile CRUD
    getEntries() / saveEntry()        — entry CRUD (sorted by date)
    getTodayEntry() / getTomorrowEntry() / getOrCreateTodayEntry()
    createTask(text, date)            — task factory with unique ID
    buildPlannedTask(task, date)      — marks task as 'planned' for promotion
    promotePlannedTasks(date)         — moves yesterday's uncompleted tasks → today
    canEditTask(task, currentDate)    — time-lock rules engine
    calculateStreak(entries)          — returns { current, longest }
    calculateMomentum(streak)         — returns { momentum, color }
    getConnections() / saveConnection() / removeConnection()
    fetchConnectionStats(connId)      — calls server proxy for live stats
    refreshAllConnections()           — batch refresh with 30-min cooldown
    exportData()                      — downloads all localStorage as JSON
    syncFromServer()                  — initial pull from Express API
    logout()                          — clears active session (keeps data)

  Task Time-Lock Rules (canEditTask):
    - task.date == today, created before today or source='planned'
        → canEdit: false (locked), canToggle: true (can check/uncheck)
    - task.date == today, created today
        → canEdit: true, canToggle: true
    - task.date == tomorrow
        → canEdit: true, canToggle: false (cannot mark complete yet)
    - task.date < today (history)
        → canEdit: false, canToggle: false (fully locked)
    - task.date > tomorrow
        → canEdit: false, canToggle: false (not allowed)

  Streak calculation:
    - A day is "complete" if ≥ 80% of tasks are completed (COMPLETION_THRESHOLD = 0.8)
    - Current streak: counts backwards from today/yesterday
    - Longest streak: longest consecutive run in history
